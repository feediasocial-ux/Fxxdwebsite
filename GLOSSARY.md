# Glosario de localización (España `es-ES` vs México `es-MX`)

Regla de oro: **nunca traducir, localizar**. Ningún texto de `/es/` debe sonar extraño en Madrid o Valencia, y ningún texto de `/mx/` debe sonar extraño en CDMX, Guadalajara o Monterrey.

| Concepto | España (`es-ES`) | México (`es-MX`) |
|---|---|---|
| Teléfono inteligente | el móvil | el celular |
| Pieza audiovisual | el vídeo | el video |
| Tratamiento plural | vosotros (tenéis, vuestro, grabáis) | ustedes (tienen, su, graban) |
| Tratamiento singular | tú (grabas, tienes) | tú (grabas, tienes) |
| Pequeña y mediana empresa | pymes | PyMEs / negocios |
| Servicio principal (SEO) | gestión de redes sociales / community manager | manejo de redes sociales / community manager |
| Sector de negocio | tu sector | tu giro |
| Conversar / contar | nos cuentas / hablamos | nos platicas / platicamos |
| Trabajo / carga operativa | trabajo / lío | chamba / operación |
| Stories de Instagram | stories | historias (o stories) |
| Informe mensual | informe mensual | reporte mensual |
| Compromiso de permanencia | sin permanencia | sin plazo forzoso |
| Letra pequeña contractual | sin letra pequeña | sin letras chiquitas |
| Moneda y formato | `349 €/mes` (sin IVA) | `MXN 3,900/mes` (IVA según corresponda) |
| Facturación | factura con IVA / asesoría | factura CFDI / contador |
| Hostelería / comida | bares, restaurantes y cafeterías (tapas, terraza, menú del día) | restaurantes, taquerías y cafeterías (comensales, sucursal, reservaciones) |
| Clínicas | clínica estética, dental o de fisioterapia (pacientes, gabinete) | clínica o consultorio estético, dental o de fisioterapia (pacientes, consultorio) |
| Inmobiliarias | pisos, chalets, propietarios, captación | departamentos, casas, desarrollos, propietarios |
